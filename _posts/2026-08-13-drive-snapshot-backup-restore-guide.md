# Drive Snapshot 备份还原攻略（PE 备份 + 客户傻瓜式还原）

> 工具：Drive Snapshot（**用官网 drivesnapshot.de 的原版 snapshot64.exe**，汉化/破解魔改版有安全风险，一律不用）
> 部署结构：**D 盘一个文件夹搞定**——`D:\RestoreTool\` 里同时放 snapshot64.exe 和系统镜像，客户还原时不用找任何东西

---

## 一、部署（一次性，装机时做）

### 1.1 目录结构（装好系统后照这个摆）

```
D:\RestoreTool\            ← 所有东西都在这一层，别建子目录
├── snapshot64.exe         ← 官方原版（拷进去）
└── 系统备份.sna           ← 备份生成的镜像（备份时直接存这里）
```

> 为什么这么设计：客户还原时 Snapshot 打开"选择镜像"默认就停在 D 盘，镜像和程序同目录，**一眼就能看到要选哪个文件**。
> 不做桌面快捷方式：快捷方式在 C 盘，还原一次就没了；客户统一从 D 盘目录启动。

---

## 二、PE 备份（做一次，安全第一）

1. 进 PE → 运行 `snapshot64.exe`
2. 点 **Backup** → 勾选 **C 盘**（系统分区）
3. 目标位置选 **`D:\RestoreTool\`**，文件名 `系统备份.sna`
4. 选项：压缩默认即可；**校验 Verify 首次全量备份时勾一次**（确保黄金状态镜像可靠，代价是时间翻倍）
5. 点 **Start** → 等进度条 → 完成后正常重启进系统
6. **首次备份后演练一次还原**（确认流程无误再交付客户）

> 以后按需全量：装新软件、大更新后再重新备份一次即可，不用增量。

---

## 三、客户还原流程（打印贴电脑旁 / 微信发客户）

| 步骤 | 操作 |
|---|---|
| 1 | 打开「此电脑」→ 进 **D 盘** → 打开 **RestoreTool** 文件夹(也可能压根不创建文件夹) → 双击 **snapshot64.exe** |
| 2 | 点主界面左侧按钮列表中的第 2 个按钮「**还原**」 |
| 3 | 在弹出的文件窗口里选「系统备份.sna」，点「**打开**」 |
| 4 | 选「C:」那一行，点「**还原**」 |
| 5 | 确认框点「**确定 / 重启**」 |
| 6 | 电脑自动重启 → 自动还原 → 自动再开机（全程不用操作） |
| 7 | 开机后试试平时用的软件能不能正常打开 |

> ⚠️ 还原只恢复 C 盘，D 盘数据不会动，放心操作

---

## 四、注意事项

| 事项 | 说明 |
|---|---|
| 文件位置 | 镜像 + exe 都在 `D:\RestoreTool\`，**绝不放 C 盘** |
| 还原影响 | 只覆盖 C 盘，D 盘数据不受影响 |
| 数据丢失 | C 盘恢复到备份时刻，**备份后新装/新增的会消失**（提前告知客户） |
| 备份时机 | 首次部署完成后立刻备份（黄金状态）；之后装新软件/大更新后再全量一次 |
| UEFI 机器 | 还原 C 盘不会动 ESP 引导分区，正常不会丢引导；保险起见 PE 备份时把 ESP（100MB）也勾选备份。万一引导丢失（开机找不到启动设备）：PE 里"引导修复"或 `bcdboot C:\Windows /s S: /f UEFI`，5 分钟修复 |
| 演练 | 首次备份后还原演练一次再交付客户 |

## 五、常见问题

**Q：客户不知道从哪里打开还原工具？**
→ 让客户打开"此电脑 → D 盘 → RestoreTool 文件夹（也可不创建文件夹） → 双击 snapshot64.exe"（告诉客户记这一个路径就行）。

**Q：还原后软件提示要激活/重新注册？**
→ 同一台硬件还原，授权一般不受影响；若提示激活，联系软件供应商走正常激活流程。

**Q：还原进行到一半断电了？**
→ 重启后重新走还原流程即可，Snapshot 对中断有保护，不会把系统搞更坏。

**Q：客户误把还原点了，怎么取消？**
→ 还原开始的确认框有取消按钮；已经开始还原了就别断电，让它跑完（还原过程中断比还原本身更危险）。
